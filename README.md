# TaskManagement

RaiseTech AIコースのカリキュラムの一環として作成する、タスク管理アプリケーションです。

## 目的

- RaiseTech AIコースのカリキュラムに沿って、AI（Claude Code）を活用した開発の進め方を学ぶ
- Gitによるバージョン管理を実践する
- タスク管理アプリの作成を通して、設計から実装までの流れを経験する

## 機能（予定）

- タスクの追加
- タスクの一覧表示
- タスクの編集
- タスクの完了・削除

※ カリキュラムの進行に合わせて追加・変更します。
