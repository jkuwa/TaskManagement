# ユースケース：Trello風タスク管理アプリ

利用者がアプリをどう使うかを、必須の機能の範囲で示す。機能の ID は [要件定義書](requirements.md) の「3. 機能要件」を参照。

## UC-01 やることを登録する

使う機能：F-11〜F-16

1. ボードを開く
2. 「未着手」列にタイトルを入力して、カードを追加する
3. 必要ならカードを開き、説明文・期限・優先度を設定する

## UC-02 やることを確認する

使う機能：F-01, F-12, F-17

1. ボードを開く
2. 各列のカードのタイトル・期限・優先度を見て、次に取りかかるものを決める
3. 詳しく知りたいカードを開いて、説明文を読む

## UC-03 進み具合を更新する

使う機能：F-19

1. 取りかかったカードを「進行中」列へドラッグする
2. 終わったカードを「完了」列へドラッグする

## UC-04 内容を変更する

使う機能：F-12〜F-16

1. カードを開く
2. タイトル・説明文・期限・優先度を書き換える
3. 詳細画面を閉じる

## UC-05 不要なカードを削除する

使う機能：F-12, F-18

1. カードを開く
2. ［削除］を押し、確認で「OK」を選ぶ

## UC-06 続きから使う

使う機能：F-31, F-32

1. ブラウザを閉じる
2. 後日、アプリを起動してブラウザで開く
3. 前回の状態のボードが表示される
