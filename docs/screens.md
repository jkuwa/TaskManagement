# 画面設計：Trello風タスク管理アプリ

画面は「ボード画面」と「カード詳細画面」の2つ。画面や操作の細かい仕様は [詳細仕様メモ](spec.md) を参照。

## ボード画面（メイン）

```
+--------------------------------------------------+
| タスク管理ボード                                 |
+----------------+----------------+----------------+
| 未着手         | 進行中         | 完了           |
| +------------+ | +------------+ | +------------+ |
| | 資料を作る | | | API調査    | | | 環境構築   | |
| | [高]11/20 ≡| | | [中] 1/3   | | |            | |
| +------------+ | +------------+ | +------------+ |
| [+ カード追加] | [+ カード追加] | [+ カード追加] |
+----------------+----------------+----------------+
```

- `[高]` `[中]`：優先度
- `11/20`：期限
- `≡`：説明文が入っていることを示すアイコン
- `1/3`：サブタスクの進み具合（3つのうち1つが完了）。任意の機能（F-24）のため未実装
- `[+ カード追加]`：押すと、その場にタイトルの入力欄と［追加］［キャンセル］ボタンが出る

## カード詳細画面（ポップアップ）

```
+----------------------------------+
| タイトル：[資料を作る          ] |
| 説明文：  [                    ] |
|           [                    ] |
| 期限：    [2026/11/20] [解除]    |
| 優先度：  [高 v]                 |
| サブタスク：                     |
|   [x] 構成を考える         (x)   |
|   [ ] 下書きを書く         (x)   |
|   [+ サブタスクを追加]           |
|                                  |
| [削除]                 [閉じる]  |
+----------------------------------+
```

- `[解除]`：期限を外すボタン。期限が入っているときだけ表示する
- `[高 v]`：優先度を選ぶプルダウン。「なし」「高」「中」「低」から選ぶ（「なし」で優先度を外す）
- `[x]` `[ ]`：サブタスクの完了・未完了
- `(x)`：サブタスクを削除するボタン
- サブタスクは追加（F-21）だけを実装している。チェックボックスは完了したかを表示するだけで、完了・未完了の切り替え（F-22）と削除の `(x)`（F-23）は未実装
- ［保存］ボタンはない。入力した内容は自動で保存する
