# 画面設計：Trello風タスク管理アプリ

画面は「ボード画面」と「カード詳細画面」の2つ。画面や操作の細かい仕様は [詳細仕様メモ](spec.md) を参照。

## ボード画面（メイン）

```
+--------------------------------------------------+
| タスク管理ボード                                 |
+----------------+----------------+----------------+
| 未着手         | 進行中         | 完了           |
| +------------+ | +------------+ | +------------+ |
| | 資料を作る | | | API調査    | | | 環境構築   | |
| | [高]11/20 ≡| | | [中] 1/3   | | |            | |
| +------------+ | +------------+ | +------------+ |
| [+ カード追加] | [+ カード追加] | [+ カード追加] |
+----------------+----------------+----------------+
```

- `[高]` `[中]`：優先度
- `11/20`：期限
- `≡`：説明文が入っていることを示すアイコン
- `1/3`：サブタスクの進み具合（3つのうち1つが完了）

## カード詳細画面（ポップアップ）

```
+----------------------------------+
| タイトル：[資料を作る          ] |
| 説明文：  [                    ] |
|           [                    ] |
| 期限：    [2026/11/20]           |
| 優先度：  [高 v]                 |
| サブタスク：                     |
|   [x] 構成を考える         (x)   |
|   [ ] 下書きを書く         (x)   |
|   [+ サブタスクを追加]           |
|                                  |
| [削除]                 [閉じる]  |
+----------------------------------+
```

- `[x]` `[ ]`：サブタスクの完了・未完了
- `(x)`：サブタスクを削除するボタン
- `[高 v]`：優先度を選ぶプルダウン
