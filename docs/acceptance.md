# 受け入れ基準：Trello風タスク管理アプリ

必須の機能について、次の確認をすべて満たしたら完成とする。確認は Google Chrome の最新版で、手で操作して行う。

## 1. 要件の確認

[要件定義書](requirements.md) の内容を確認する。

| ID | 確認すること | 期待する結果 |
|---|---|---|
| F-01 | データが空の状態でアプリを開く | 「未着手」「進行中」「完了」の3列が左から順に並んでいる |
| F-11 | 「未着手」列でタイトルを入力して追加する | 未着手列にカードが表示される |
| F-11 | タイトルを空のまま追加する | カードは作られない |
| F-12 | ボード上のカードをクリックする | 詳細画面が開き、そのカードの内容が表示される |
| F-12 | 詳細画面で［閉じる］を押す | 詳細画面が閉じる |
| F-13 | 詳細画面でタイトルを変えて閉じる | ボード上のカードのタイトルが変わっている |
| F-14 | 詳細画面で説明文を入力して閉じ、もう一度開く | 入力した説明文が表示される |
| F-15 | 詳細画面で期限を設定する | ボード上のカードに期限が表示される |
| F-15 | 設定した期限を解除する | ボード上のカードから期限の表示が消える |
| F-16 | 詳細画面で優先度を「高」にする | ボード上のカードに優先度「高」が表示される |
| F-16 | 設定した優先度を解除する | ボード上のカードから優先度の表示が消える |
| F-17 | 説明文を入力したカードを見る | ボード上のカードに説明文のアイコンが表示される |
| F-17 | 期限・優先度・説明文を設定していないカードを見る | タイトルだけが表示される |
| F-18 | 詳細画面で［削除］を押し、確認で「OK」を選ぶ | カードが消える |
| F-18 | 詳細画面で［削除］を押し、確認で「キャンセル」を選ぶ | カードは消えない |
| F-19 | 「未着手」のカードを「進行中」列へドラッグ&ドロップする | カードが進行中列に移る |
| F-20 | 「未着手」列の一番下のカードを、同じ列の一番上へドラッグ&ドロップする | カードが未着手列の一番上に移る |
| F-31, F-32 | カードの追加・編集・移動・並べ替え・削除をしてからページを再読み込みする | 再読み込みする前と同じ状態が表示される |
| F-32 | ブラウザとバックエンドを止めて起動し直し、アプリを開く | 止める前と同じ状態が表示される |
| 非機能 | タイトルに `<b>太字</b>` と入力してカードを追加する | 太字にはならず、`<b>太字</b>` という文字のまま表示される |
| 非機能 | ブラウザの横幅を 1280px にしてボードを開く | 横スクロールなしで3列が表示される |

## 2. 詳細仕様の確認

[詳細仕様メモ](spec.md) の内容を確認する。詳細仕様メモは作り込みのときに見直すことがあるので、仕様を変えたときはこの表もあわせて直す。

| ID | 確認すること | 期待する結果 |
|---|---|---|
| F-11 | 「未着手」列でタイトルを入力して追加する | 未着手列の一番下にカードが表示される |
| F-11 | タイトルを空白だけにして追加する | カードは作られない |
| F-11 | タイトルに101文字以上を入力しようとする | 100文字までしか入力できない |
| F-12 | 詳細画面で Esc キーを押す | 詳細画面が閉じる |
| F-12 | 詳細画面の外側をクリックする | 詳細画面が閉じる |
| F-13 | 詳細画面でタイトルを空にして閉じる | 変更前のタイトルのままになる |
| F-14 | 詳細画面で説明文を入力し、閉じずにページを再読み込みする | 入力した説明文が保存されている |
| F-17 | 詳細画面で期限を 2026年11月20日 に設定する | ボード上のカードに「11/20」と表示され、詳細画面では「2026/11/20」と表示される |
| F-17 | 詳細画面で期限を 2027年1月5日 に設定する | ボード上のカードに「1/5」と表示される |
| F-17 | 説明文を空白だけにして閉じる | ボード上のカードに説明文のアイコンは表示されない |
| F-18 | 詳細画面で［削除］を押す | 「このカードを削除しますか？」と表示される |
| F-18 | 列の一番上のカードを削除してから、その列の一番下へ別のカードを追加・移動し、ページを再読み込みする | 並び順が再読み込みの前と変わらない |
| F-18 | 詳細画面で説明文を入力し、すぐに［削除］→「OK」を選ぶ | カードが消え、「保存できませんでした」は表示されない |
| F-19 | 「未着手」のカードを「進行中」列の2枚のカードの間へドラッグ&ドロップする | カードが進行中列の、落とした2枚の間に入る |
| F-19, F-20 | カードをドラッグしている間、列の上で動かす | カードが入る位置に線が表示される |
