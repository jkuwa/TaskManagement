# 詳細仕様メモ：Trello風タスク管理アプリ

[要件定義書](requirements.md) を補う、画面や操作の細かい仕様をまとめる。作り込みのときに見直してよい。

必須の機能と、作った任意の機能（サブタスク）を対象とする。ほかの任意の機能の細かい仕様は、作るときに決めてここに足す。

## 1. カード

| 関係する機能 | 仕様 |
|---|---|
| F-11 | 列の下の［＋ カード追加］を押すと、タイトルの入力欄と［追加］［キャンセル］が出る |
| F-11 | ［追加］か Enter キーでカードを追加する。追加したあとも入力欄は空にして開いたままにし、続けて追加できる |
| F-11 | ［キャンセル］か Esc キーで入力欄を閉じる（入力していた文字は消える） |
| F-11 | 追加に失敗したときは、入力した文字を残したまま「保存できませんでした」を表示する |
| F-11 | 新しいカードは、列の一番下に追加する |
| F-11 | 空白だけのタイトルは、空のタイトルと同じ扱いにする（カードを作らない） |
| F-11, F-13 | タイトルは100文字まで入力できる。説明文に文字数の上限はない |
| F-11, F-13 | 文字数は、フロントエンドの入力欄（maxLength）とバックエンドの入力チェック（@Size）で同じ数え方をする。絵文字などは1つで2文字と数える |
| F-13 | 詳細画面でタイトルを空にして閉じた場合は保存せず、変更前のタイトルに戻す |
| F-15 | 期限は日付の入力欄で選ぶ。期限が入っているときは横に［解除］ボタンを出し、押すと期限を外す |
| F-16 | 優先度はプルダウンで「なし」「高」「中」「低」から選ぶ。「なし」を選ぶと優先度を外す |
| F-17 | ボード上の期限は「11/20」のように月/日だけで表示する（月・日の頭に0は付けない。例：1/5）。西暦は詳細画面でだけ表示する |
| F-17 | 説明文が入っているカードには、ボード上で「≡」アイコンを表示する。空白だけの説明文は入っていない扱いにする |
| F-18 | 詳細画面の［削除］を押すと「このカードを削除しますか？」と確認を表示する。「OK」で削除し、詳細画面を閉じる |
| F-18 | 削除は DB からデータを消す（元に戻せない）。同じ列の残りのカードは上に詰める |
| F-18 | 削除に失敗したときは、詳細画面を開いたまま「保存できませんでした」を表示する |
| F-19 | 別の列へ移動したカードは、移動先の列の落とした位置に入る |
| F-20 | 同じ列の中で動かしたカードは、落とした位置に入る |
| F-19, F-20 | ドラッグ中は、カードが入る位置に線を表示する |

## 2. 詳細画面

| 関係する機能 | 仕様 |
|---|---|
| F-12 | ［閉じる］ボタン、Esc キー、詳細画面の外側のクリックのどれでも閉じる |
| F-14, F-31 | 文字を入力するたびに自動で保存する（［保存］ボタンは置かない） |
| F-13〜F-16, F-31 | 保存は入力が 0.5 秒止まってから行う（1文字ごとに通信しないため）。閉じるときは待たずにすぐ保存する |
| F-31 | 詳細画面を閉じたあとに保存に失敗したときは、ボードの上に「保存できませんでした」を表示する |
| F-31 | カードの内容やサブタスクの保存に失敗したときは、そのカード（サブタスク）を保存し直せるまで「保存できませんでした」を消さない。ほかのカードやサブタスクの保存が成功しても消さない |
| F-31 | 削除や移動に失敗したとき（画面の内容は保存されている状態のまま、または読み直して戻る）は、次にどれかの保存が成功したら「保存できませんでした」を消す |
| F-19, F-20, F-31 | カードを移動できたときは、ボード全体を保存されている状態で表示し直し、「保存できませんでした」を消す |
| F-31 | カードの内容か、そのカードのサブタスクの保存に失敗したままのときは、ボードのそのカードのタイトルの右に「⚠」を出し、赤い枠を付ける。保存し直せたら外す |
| F-31 | サブタスクの保存に失敗したままのときは、詳細画面のそのサブタスクの行（［×］の左）に「⚠未保存」を出す。保存し直せたら外す |
| F-31 | 削除の失敗や、移動に失敗して読み直しもできなかったときは、どこの失敗か示せないので印は付けず、「保存できませんでした」だけを表示する |

## 3. サブタスク

| 関係する機能 | 仕様 |
|---|---|
| F-21 | 詳細画面の［＋ サブタスクを追加］を押すと、内容の入力欄と［追加］［キャンセル］が出る |
| F-21 | ［追加］か Enter キーでサブタスクを追加する。追加したあとも入力欄は空にして開いたままにし、続けて追加できる |
| F-21 | ［キャンセル］か Esc キーで入力欄を閉じる（入力していた文字は消える）。このとき詳細画面は閉じない。もう一度 Esc キーを押すと詳細画面が閉じる |
| F-21 | 追加に失敗したときは、入力した文字を残したまま「保存できませんでした」を表示する |
| F-21 | 新しいサブタスクは未完了で、一覧の一番下に追加する。サブタスクは追加した順に並び、並べ替えはできない |
| F-21 | 空白だけの内容は、空の内容と同じ扱いにする（サブタスクを作らない） |
| F-21 | 内容は100文字まで入力できる。数え方はカードのタイトルと同じ（絵文字などは1つで2文字と数える） |
| F-21 | 完了したサブタスクは、チェックを付け、内容に打ち消し線を引いて表示する |
| F-22 | チェックボックスを押すと、完了・未完了を切り替えてすぐに保存する |
| F-26 | 内容の文字を押すと入力欄に変わり、書き換えられる（文字を押してもチェックは切り替わらない） |
| F-26 | Enter キーか、入力欄の外をクリックすると確定して保存し、文字の表示に戻る |
| F-26 | Esc キーで変更を取り消して文字の表示に戻る。このとき詳細画面は閉じない。もう一度 Esc キーを押すと詳細画面が閉じる |
| F-26 | 内容を空や空白だけにして確定したときは、保存せずに元の内容に戻す。前後の空白は取り除き、100文字まで入力できる（追加のときと同じ） |
| F-22, F-26 | 保存に失敗したときは、画面は操作したまま（チェック・内容はそのまま）にして「保存できませんでした」を表示する |
| F-23 | 各サブタスクの右端の［×］を押すと、確認せずにすぐ削除する |
| F-23 | 削除に失敗したときは、サブタスクを一覧に残したまま「保存できませんでした」を表示する |
| F-18 | カードを削除すると、そのカードのサブタスクも削除する |
| F-24 | ボード上のカードに、サブタスクの進み具合を「☑ 1/3」（完了の数/全部の数）の形で、優先度・期限のあと（説明文アイコンの前）に表示する |
| F-24 | サブタスクが1件もないカードには、進み具合を表示しない |
| F-24 | 普段は灰色で、全部完了したとき（例：3/3）だけ緑色にする |
| F-24 | 詳細画面でサブタスクを追加・切り替え・削除すると、ボード上の進み具合にもすぐ反映する |

## 4. メッセージ

| 場面 | 表示する文言 |
|---|---|
| 保存に失敗したとき | 保存できませんでした |
| データを読み込めないとき | データを読み込めませんでした |

この仕様の確認項目は、[受け入れ基準](acceptance.md) の「2. 詳細仕様の確認」にまとめる。仕様を変えたときは、確認項目もあわせて直す。
