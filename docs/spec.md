# 詳細仕様メモ：Trello風タスク管理アプリ

[要件定義書](requirements.md) を補う、画面や操作の細かい仕様をまとめる。作り込みのときに見直してよい。

対象は必須の機能だけとする。任意の機能の細かい仕様は、作るときに決める。

## 1. カード

| 関係する機能 | 仕様 |
|---|---|
| F-11 | 新しいカードは、列の一番下に追加する |
| F-11 | 空白だけのタイトルは、空のタイトルと同じ扱いにする（カードを作らない） |
| F-11, F-13 | タイトルは100文字まで入力できる。説明文に文字数の上限はない |
| F-13 | 詳細画面でタイトルを空にして閉じた場合は保存せず、変更前のタイトルに戻す |
| F-17 | ボード上の期限は「2026/11/20」のように西暦から表示する |
| F-19 | 別の列へ移動したカードは、移動先の列の一番下に入る |

## 2. 詳細画面

| 関係する機能 | 仕様 |
|---|---|
| F-12 | ［閉じる］ボタンか Esc キーで閉じる。詳細画面の外側をクリックしても閉じない |
| F-14, F-31 | 文字を入力するたびに自動で保存する（［保存］ボタンは置かない） |

## 3. メッセージ

| 場面 | 表示する文言 |
|---|---|
| 保存に失敗したとき | 保存できませんでした |
| データを読み込めないとき | データを読み込めませんでした |

この仕様の確認項目は、[受け入れ基準](acceptance.md) の「2. 詳細仕様の確認」にまとめる。仕様を変えたときは、確認項目もあわせて直す。
